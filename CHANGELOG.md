# Changelog

## 1.0.0 (2026-10-06)

First npm release.

- `npx framegrove mcp` starts the MCP server; no clone or zip needed.
- CLI: `templates`, `outputs`, `render`, `project`, `inspect`, `fonts`, `--help`, `--version`; English is the default caption language.
- Template fonts download once on first render to `~/.cache/framegrove/fonts`.
- MCP tools carry titles and read-only annotations.
- Template placeholders such as "YOUR APP" are replaced by the app name; screens without an icon no longer show a placeholder glyph.
- Claude Code plugin (MCP server plus agent skill) and MCP Registry entry `io.github.tech-bam/framegrove`.
- 56 curated templates, 172 editable compositions, App Store Creative Assets and iPhone Duo series.
