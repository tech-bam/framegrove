Frequently asked questions

Is it really free?

Yes. The editor, templates and exports run entirely in your browser. Nothing is uploaded; projects are stored on your device and can be exported as a file.

Which sizes are included?

All current App Store Connect sizes (6.9", 6.7", 6.5", 6.3", 6.1", 5.5", iPad 13"/12.9"/11", Watch, Mac, Vision Pro) and Google Play sizes (phones, tablets, feature graphic, Wear OS), plus Amazon, Huawei and Microsoft presets.

Can I design once and export for every device?

Yes. Layouts are responsive: positions are relative to the canvas, so one design adapts across aspect ratios. Each device family can also have its own raw screenshot.

How does the AI work?

The AI panel in the editor writes captions from a short description and translates them into every project language. It calls Anthropic directly with your own API key, which is sent directly to Anthropic for authentication. Without a key, copy the prompt and paste the answer.

Can an AI agent generate my screenshots?

Yes — the MCP server and CLI use the same rendering engine in Node, so Claude Code or any MCP client can render a full set to PNG files. See the MCP page.

Do I need Figma or Photoshop?

No. Everything happens in the canvas editor. Exact Dimensions gives pixel-level control when you need it.
