# Framegrove template catalog

All current templates are free and have editable text, device frames, shapes and backgrounds. Legacy template keys remain resolvable for saved projects but are excluded from the current catalog.

## Collections

- Phone: `studio-paper`, `studio-midnight`, `studio-lime`, `studio-clay`, `studio-cobalt`, `studio-mono`, `studio-peach`, `studio-tide`, `studio-ledger`, `studio-orchid`, `studio-signal`, `studio-sand`, `studio-ruby`, `studio-ice`, `studio-ink`, `studio-apricot`. Six screens each.
- Tablet: `tablet-paper`, `tablet-midnight`, `tablet-lime`, `tablet-clay`. Four screens each.
- Creative: `creative-{paper|midnight|lime|clay|cobalt|mono|peach|tide}-{header|search|universal}`. One composition each.
- Duo: `duo-{paper|midnight|lime|cobalt}-{outer|inner|inner-landscape}`. Three screens each.

Use the MCP `list_templates` response as the current source of truth for names, `collection`, `sizes`, orientation and screen count. Sample captions are EN/TR and should be replaced with verified app benefits.
