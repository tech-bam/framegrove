# Security

Framegrove runs locally: the web editor keeps projects in the browser, and the MCP server and CLI read and write only the paths you pass them. Optional AI features in the web editor call your chosen provider with your own key; Framegrove has no server that receives it.

Report a vulnerability privately through [GitHub security advisories](https://github.com/tech-bam/framegrove/security/advisories/new) or by email to merhaba@bamstudio.dev. Please do not open a public issue. You can expect a reply within a week.

Supported version: the latest npm release and the live site.
